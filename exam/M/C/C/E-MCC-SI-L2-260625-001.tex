光滑圆轨道固定在竖直面内，一质量为\(m\)的小球沿轨道做完整的圆周运动，已知小球在最低点时对轨道的压力大小为\(N_1\)，速度大小为\(v_1\)，在最高点时对轨道的压力大小为\(N_2\)，速度大小为\(v_2\)，重力加速度大小为\(g\)，且\(v_1\)、\(v_2\)满足关系式\(v_1^2 - v_2^2 = 4gR\)，则\(N_1 - N_2\)的值为\paren[]
\begin{choices}
    \item \(3mg\)
    \item \(4mg\)
    \item \(5mg\)
    \item \(6mg\)
\end{choices}
