“嫦娥六号”探测器于 2024年5月8日进入环月轨道，后续经调整环月轨道高度和倾角，实施月球背面软着陆。当探测器的轨道半径从 \(r_1\) 调整到 \(r_2\) 时（两轨道均可视为圆形轨道），其动能和周期从 \(E_{k1}\)、\(T_1\) 分别变为 \(E_{k2}\)、\(T_2\)。下列选项正确的是\paren[]
\begin{choices}
	\item \(\dfrac{E_{k1}}{E_{k2}} = \dfrac{r_2}{r_1}\),\: \(\dfrac{T_1}{T_2} = \dfrac{\sqrt{r_1^3}}{\sqrt{r_2^3}}\)
	\item \(\dfrac{E_{k1}}{E_{k2}} = \dfrac{r_1}{r_2}\),\: \(\dfrac{T_1}{T_2} = \dfrac{\sqrt{r_1^3}}{\sqrt{r_2^3}}\)
	\item \(\dfrac{E_{k1}}{E_{k2}} = \dfrac{r_2}{r_1}\),\: \(\dfrac{T_1}{T_2} = \dfrac{\sqrt{r_2^3}}{\sqrt{r_1^3}}\)
	\item \(\dfrac{E_{k1}}{E_{k2}} = \dfrac{r_1}{r_2}\),\: \(\dfrac{T_1}{T_2} = \dfrac{\sqrt{r_2^3}}{\sqrt{r_1^3}}\)
\end{choices}
\begin{answer}
	A\qquad 提示：万有引力提供向心力
\end{answer}
